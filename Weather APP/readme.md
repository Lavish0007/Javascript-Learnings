The Project

Weather App (Build this first)
Features
Input box for city name
Search button
Fetch live weather data from a free API
Display temperature, condition, and city name
Show "Loading..." while fetching
Show an error for invalid cities/API failures
Stretch: Remember the last searched city using localStorage
Skills You'll Practice

fetch • async/await • try/catch • DOM manipulation • error handling • basic state management

Free API

Open-Meteo — no API key, no signup.
Docs: https://open-meteo.com/en/docs

Resources to USE
Resource	For
MDN Web Docs	Syntax & concepts (fetch, async/await, JSON.parse, etc.)
Open-Meteo Docs	Understanding the API response
Browser Console	Reading and debugging errors
JavaScript30	Vanilla JS practice after this project
Stack Overflow	Only for specific errors
Resources to AVOID

❌ ChatGPT / Claude / AI — Don't use AI to write the code.
❌ Full YouTube tutorials — Don't follow "Build a Weather App in 20 minutes" tutorials.
❌ Copy-pasted boilerplate — Type and understand everything yourself.

🆘 If You're Stuck

If you're stuck on the same problem for 30+ minutes:

Check MDN
Read the browser console
Search the exact error on Stack Overflow
As a last resort, watch only the relevant 2-minute section of a tutorial

Then close it and implement the solution yourself.
